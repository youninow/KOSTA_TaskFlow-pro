# 01. Product — TaskFlow Pro

## 목표

> **"지금 누가 뭐 해?"** 라는 질문이 사라지게 만든다.

팀 업무를 한 화면에서 시각화해, 별도 보고 없이도 전체 진행 상황을 파악할 수 있는 환경을 만든다.

---

## 페르소나

| 항목 | 내용 |
|------|------|
| **대상** | 10명 규모 스타트업의 팀리더 |
| **연령대** | 30~40대 |
| **상황** | 슬랙·카카오로 상태를 묻는 데 하루 30분 이상 소모 |
| **니즈** | 팀원 업무 현황을 실시간에 가깝게 한눈에 파악 |
| **기피** | 복잡한 도구, 긴 온보딩, 추가 앱 설치 |

---

## MVP 범위

### 핵심 기능

#### CRUD 4종 — 모두 화면에서 동작

| 기능 | 설명 |
|------|------|
| **추가 (Create)** | 폼에서 태스크 생성 |
| **목록 (Read)** | 전체 태스크 목록 조회 |
| **수정 (Update)** | 인라인 또는 모달에서 편집 |
| **삭제 (Delete)** | 확인 후 삭제 |

#### 상태 분류

태스크는 다음 3가지 상태 중 하나를 갖는다.

```
todo  →  in_progress  →  done
```

#### 마감 시각 (due_at)

- 날짜만이 아닌 **시간까지** 지정한다.
- 저장 형식: `YYYY-MM-DD HH:mm` (예: `2026-05-12 18:00`)
- UI 입력: `<input type="datetime-local">`

#### 라이트 / 다크 테마 토글

- 버튼 한 번으로 전환
- 선택값은 `localStorage`에 저장 → 새로고침 후에도 유지

#### 모바일 반응형

- 최소 지원 너비: **360px**
- 360px에서 레이아웃 깨짐 없음을 성공 기준으로 삼는다.

### UI 톤 — macOS 스타일

| 요소 | 적용 방식 |
|------|----------|
| 모서리 | 둥근 모서리 (`border-radius` 12px 이상) |
| 그림자 | 부드러운 다층 그림자 (`box-shadow`) |
| 카드 | 반투명 배경 (`backdrop-filter: blur`) |
| 폰트 | 시스템 폰트 스택 (`-apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`) |

## 확장 로드맵 (MVP 이후)

아래 기능은 MVP 완료 후 순차적으로 검토한다. **현재 설계에 영향을 주지 않는다.**

| 기능 | 비고 |
|------|------|
| JWT 로그인 | 인증·인가 레이어 추가 |
| 팀 / 멤버 관리 | 다중 사용자 지원 |
| Kanban 보드 | 드래그앤드롭 뷰 전환 |
| 채팅 | 태스크 단위 코멘트 |
| CI/CD | 배포 자동화 파이프라인 |

---

## MVP 범위 외 (명시적 제외)

아래는 MVP에서 구현하지 않는다. 요청이 들어와도 범위 밖임을 안내한다.

| 항목 | 이유 |
|------|------|
| 외부 결제 | 과금 모델 미결정 |
| 네이티브 앱 | 웹 우선 전략 |
| WebRTC | 인프라 복잡도 과다 |
| 외부 캘린더 연동 | OAuth 범위 초과 |
| 파일 업로드 | 스토리지 설계 별도 필요 |
| WebSocket | MVP는 **폴링(polling)** 으로 대체, WebSocket은 확장 단계로 보류 |

## 성공 기준

MVP가 완료되었다고 판단하려면 아래 **6가지 조건을 모두 충족**해야 한다.

| # | 기준 | 측정 방법 |
|---|------|----------|
| 1 | 새로고침 후 데이터 유지 | DB 저장 확인 |
| 2 | 360px에서 레이아웃 깨짐 없음 | 브라우저 DevTools 360px 뷰 |
| 3 | API 응답 200ms 이내 | 네트워크 탭 또는 서버 로그 |
| 4 | CRUD 4종 화면에서 모두 동작 | 수동 E2E 시나리오 통과 |
| 5 | 테마 토글 작동 | 전환 후 새로고침 시 상태 유지 확인 |
| 6 | due_at 시간 단위 저장·표시 | `2026-05-12 18:00` 형식으로 DB 저장 및 화면 출력 확인 |
